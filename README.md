# Hi there, I'm ciefp 👋

I'm a developer focused on embedded TV middleware and user-facing tooling for Enigma2 / OpenPLi devices. I build small, reliable plugins and scripts that make installation and configuration easier — especially around T2MI Abertis support.

- 🔭 I maintain plugins and automation for OpenPLi Enigma2 devices.
- ⚙️ Primary languages: Lua, Python, Shell.
- 🌱 I enjoy improving deployment and configuration workflows for embedded Linux systems.
- 💬 Ask me about Enigma2 plugins, T2MI streams, or scripting for satellite/terrestrial receivers.

---

## Spotlight: T2MI Abertis OpenPLi plugin
My ongoing project for easy installation of T2MI Abertis support on OpenPLi Enigma2 devices:

- Repository: [CiefpSettingsT2miAbertisOpenPLi](https://github.com/ciefp/CiefpSettingsT2miAbertisOpenPLi)  
  This plugin is intended for easy installation of the necessary configurations and scripts for using T2MI Abertis functionality on OpenPLi Enigma2 devices.

If you're looking for installation details, troubleshooting tips, or want to adapt the plugin to your image / receiver model, check the repository README or open an issue there.

## Quick example — how I like to ship plugins
Here's the typical, minimal workflow I follow when preparing a plugin for users (high level):

```bash
# clone the repo (on a dev machine or directly on the receiver if supported)
git clone https://github.com/ciefp/CiefpSettingsT2miAbertisOpenPLi.git

# inspect instructions inside the repo
cd CiefpSettingsT2miAbertisOpenPLi
# Read the repository README for specific installation steps for your image/device
```

(Always follow the repo README for device-specific steps — receivers and images vary.)

## How to collaborate
- Found a bug or need support? Open an issue in the repository and include:
  - Device model, image version, and steps to reproduce.
  - Logs or screenshots where helpful.
- Want to contribute? Fork the repo, create a branch, and submit a PR with:
  - A clear description of the change
  - Why it's needed
  - Testing steps (what you ran, where you tested)
